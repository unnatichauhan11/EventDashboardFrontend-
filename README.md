📅 Event Dashboard

A responsive, frontend-only Event Dashboard built using HTML, CSS, and JavaScript. It provides a simple interface to manage events, users, projects, feedback, and suggestions.

✨ Features

* Dashboard: View statistics for events, users, projects, and suggestions.
* Event Management: Create, edit, search, and delete events.
* User Management: Add, search, and delete users.
* Project Management: Create projects, search projects, and update their status.
* Feedback: Submit and manage feedback.
* Suggestions: Submit suggestions and mark them as reviewed.
* Preferences: Customize your display name, enable dark mode, and switch to a compact layout.
* Responsive Design: Use the dashboard on desktop, tablet, and mobile devices.
* Local Data Storage: Save application data in the browser using localStorage.

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

🚀 Getting Started

Option 1: Run Locally

1. Clone this repository:
git clone https://github.com/unnatichauhan11/EventDashboardFrontend-.git


2. Open the project folder in Visual Studio Code.
3. Open index.html using the Live Server extension.

Alternatively, open index.html directly in your browser.

Option 2: Use GitHub Pages

1. Open your GitHub repository.
2. Go to Settings → Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Select your main branch and the root folder (/).
5. Click Save.
6. Wait for GitHub Pages to publish your website.

💾 Data Storage

This application uses browser localStorage to save events, users, projects, feedback, suggestions, and preferences.

Note: Data is stored locally in the browser. It is not shared or synchronized between different devices or browsers. Clearing browser storage may delete the saved application data.
